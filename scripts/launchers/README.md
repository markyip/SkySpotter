# Launcher scripts

Run from the **project root** (examples):

| Platform | Dev launch | Train | Verify | Build |
|----------|------------|-------|--------|-------|
| **Windows** | `scripts\launchers\launch_dev.bat` | `scripts\launchers\train_model.bat` | `scripts\launchers\verify_model.bat` | `scripts\launchers\build_windows.bat` |
| **macOS** | `./scripts/launchers/launch_dev.sh` | `./scripts/launchers/train_model.sh` | `./scripts/launchers/verify_model.sh` | `./scripts/launchers/build_macos.sh` |

`uninstall.bat` stays at the repo root — it is tied to the installed app layout.
